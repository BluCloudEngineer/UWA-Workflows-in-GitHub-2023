# How to Contribute

Thank you for your interest in my repository and feel free to participate and contribute to it! You can either work by yourself or as a team (preferred).

## Submitting Changes

### Desired Changes

1. Please look at the [Issues](https://github.com/BluCloudEngineer/UWA-Workflows-in-GitHub-2023/issues) page and choose an issue that you want to work on.
2. Focus on these issues first.

### Additional Features

1. If there are no more [Issues](https://github.com/BluCloudEngineer/UWA-Workflows-in-GitHub-2023/issues) to address or you want to do something more advanced or add something really cool, then feel free to create a pull request and submit it for review.

## Standard and Conventions

### Coding

1. All Python code must follow the [PEP8](https://peps.python.org/pep-0008/) coding standard.

### Git Branching

1. Do not work directly off the `main` branch, please create a new branch that follows the [Conventional Branch](https://conventionalbranch.org/) standard.

## Questions

If you need additional help, clarification or guidance, do not hesitate to ask for help.
