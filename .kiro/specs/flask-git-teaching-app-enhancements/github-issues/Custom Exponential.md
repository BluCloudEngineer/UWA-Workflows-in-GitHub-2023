# Custom Exponential

## Describe the New Feature

I want to add logic to the calculator application so that when two numbers are provided, it will calculate the first number raised to the second number.

For example, if the following POST data is sent to the application:

```python
data = {
    "operation": "custom_exponential",
    "number_1": 3, # Key and value required
    "number_2": 4  # Key and value required
}
```

The result will be:

```text
Result: 81.0
```
