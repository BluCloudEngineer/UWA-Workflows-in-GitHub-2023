# Modulus

## Describe the New Feature

I want to add logic to the calculator application so that when two numbers are provided, it will calculate the modulus (remainder) of the two numbers.

For example, if the following POST data is sent to the application:

```python
data = {
    "operation": "modulus",
    "number_1": 100, # Key and value required
    "number_2": 23   # Key and value required
}
```

The result will be:

```text
Result: 8.0
```
